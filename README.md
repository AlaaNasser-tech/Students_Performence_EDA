
# 📊 Student Performance Analysis & EDA

Welcome to the Student Performance Exploratory Data Analysis (EDA) project, created for the Data Analysis Algorithms course. This repository contains an in-depth data wrangling, cleaning, and analysis process executed in Google Colab to uncover key factors influencing student academic performance.

---

## 📌 Project Overview

The objective of this assignment is to apply end-to-end data analysis methodology—from data loading and wrangling to deep visual analysis—on the Student Performance Dataset.

The project addresses all core requirements:
1. Exploratory Data Analysis (EDA): Answering key descriptive and statistical questions about performance distribution and attribute correlations.
2. Data Wrangling & Cleaning: Handling missing values, encoding categorical attributes, structural cleaning, and feature engineering.
3. Comprehensive Markdown Explanations: Clear textual insights accompanying every single code cell and chart.

---

## 🛠️ Data Wrangling & Preprocessing Steps

- Data Inspection: Checking data types, non-null values, and summary statistics (df.info(), df.describe()).
- Data Cleaning: Handling missing entries, duplicates, and standardizing column formats.
- Categorical Encoding: Converting nominal and ordinal text variables into numerical format for analytical modeling.
- Outlier Detection: Identifying and evaluating extreme values across target performance metrics.

---

## 📈 Key Insights & Exploratory Questions Addressed

- Study Time vs. Final Grades: Evaluating the correlation between study hours/effort and final academic output.
- Socio-Demographic Factors: Analyzing how parental education, family relationships, and background impact performance.
- Absences Impact: Observing the inverse relationship between student absenteeism and overall academic scores.
- Alcohol Consumption & Social Life: Exploring the influence of weekday/weekend alcohol consumption and free time on grades.
